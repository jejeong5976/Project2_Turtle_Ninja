# swerve_track — 스워브 속도 추종 잔차 RL

`/cmd_vel` (MPPI 출력) → 몸 속도 잔차 → `nt_swerve` → 조향 · 바퀴. MPPI 는 그대로 두고 그 아래 끼우는 층 (MPPI 대체 아님).
R12 팀 주행 PPO (velog "프로젝트2 PPO 신경망 구조": 목표 속도 → 바퀴 속도 잔차, 고정 평가 RMSE) 를 참고해 2026-11-02 설계. `swerve_follow` (경로 층) 본학습 1 이 보상 문제로 개선 없었던 것 → 목표를 "명령 속도 따라가기" 하나로 좁힘.

```
Nav2 MPPI → collision_monitor → /cmd_vel ─┐
                                          ├→ [정책: 몸 속도 잔차] → nt_swerve → 조향 · 바퀴
odom · 조향각 · 바퀴 속도 · 자이로 ───────┘
```

## R12 설계와 다른 점

| 항목 | R12 | 여기 | 이유 |
|---|---|---|---|
| 행동 | 바퀴 구동 속도 잔차 4 | 몸 속도 잔차 3 (nt_swerve 앞) | 바퀴별로 고치면 역기구학이 맞춘 바퀴 사이 일관성이 깨짐 → 실물 끌림. 간이 플랜트 (최소제곱 순기구학) 는 끌림 비용을 못 봄 |
| 기울기 보상 | −10 (roll² + pitch²) | 없음 | 간이 플랜트에 roll · pitch 없음 (Isaac 검증 때 지표로만) |
| IMU | 각속도 3 · 가속도 3 | 자이로 z 1 | 평평한 바닥 플랜트 |
| 조향 비용 | 없음 | 이동량 + 범위 끝 | swerve_follow 본학습 1 에서 분기 전환 4.4 → 6.9 회 악화, 조향 끝 닿음 38 % (선 꼬임) |
| 학습 규모 | env 8 × 64 스텝 | env 16384 × 64 (torch 플랜트) | |
| critic | 1 층 128 | [256, 256] + 특권 관측 | |

| 한계 (v_max/0.26, a_max/1.0) | 2 |

- 미리보기 기본 0: 실물에서 앞 명령을 얻으려면 MPPI 내부 최적 열이 필요 (Nav2 는 경로 형태로만 냄) → 지금은 반응형만

## 행동 · 안전

- 잔차 = (Δvx, Δvy) 노름 ≤ 0.03 m/s, Δwz ≤ 0.15 rad/s (Codex 권고값). 합친 명령은 v_max · w_max 로 자름
- 목표가 정지 (‖v‖ < 0.005 · |wz| < 0.02) 면 잔차 0 → collision_monitor 정지 · `/mission/hold` 가 항상 이김

## 보상 (정책 스텝 50 ms)

| 항 | 식 |
|---|---|
| 선속도 추종 | 1.0 · exp(−‖v_xy − c_xy‖² / 0.05²) (참 몸 속도) |
| 각속도 추종 | 0.5 · exp(−(wz − c_wz)² / 0.15²) |
| 조향 이동량 | −0.2 · Σ\|Δθ\| [rad/스텝] |
| 조향 범위 끝 | −0.05 · 바퀴 평균 clip((0.1 − 끝까지 거리)/0.1, 0, 1) |
| 행동 크기 · 변화 | −0.01 ‖a‖², −0.01 ‖Δa‖² |

에피소드 = 명령 열 끝까지 (truncation, 실패 종료 없음). 조향 상태는 직전 에피소드에서 이어받음 (20 % 무작위).

## PPO

actor [128, 128] ELU · critic [256, 256] ELU, 관측 정규화, 초기 std 0.3 · **최소 std 0.02** (`std_range`), entropy 0.002, γ 0.99, λ 0.95, 64 스텝/env, 5 epoch, 4 미니배치, lr 3e-4 adaptive (kl 0.01).
