# swerve_follow — 스워브 경로 추종 RL

Nav2 플래너 경로 + 목표 자세 → 몸 속도 (vx, vy, wz) 20 Hz. 아래는 팀 스워브 컨트롤러(`nt_swerve` 규칙) 그대로 → 정책은 바퀴를 직접 안 만짐.
목적 = MPPI(`motion_model: omni`, 조향 지연 모름) 가 못 보는 조향 지연 · 조향 범위 끝(한 바퀴 못 돎) 을 아는 명령. MPPI 대체 후보 (채택은 평가 후).

설계는 Claude 초안 → Codex 검토 3회 (설계 · 수정안 · 구현 코드) 로 정함 (2026-10-30).

## 주요 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 학습 시뮬 | torch 간이 플랜트 (GPU, 4096 env) | 전체 로봇 Isaac + Python 컨트롤러는 env 수천 개 불가. Isaac 은 검증용 (미구현) |
| 행동 | **잔차** = 기준 추종기 + (Δvx, Δvy) 노름 ≤ 0.05 m/s, Δwz ≤ 0.3 rad/s | 잔차 0 = 기준선, 실패 원인 분리. Codex 는 0.03 / 0.15 권고 → 비교 실험 대상 |
| yaw | 기준 추종기가 처음부터 목표 yaw 로 (비례 1.5), 잔차가 조정 | 자유 yaw 학습 안 함 |
| 속도 한계 | {0.10/0.2, 0.13/0.2} (m/s, m/s²) 균등, 관측으로 줌. 각속도 = 1.675 × v/0.2612, 각가속 = 6 × a | 실물 확인 범위. 0.2612/1.0 은 `--hardware_profile` |
| 판정 자세 | 보상 · 도착 · 이탈 = 현재 추정 자세 (참 + 위치 오차, 지연 없음) | Nav2 goal checker 와 같음. 위치 오차는 컨트롤러가 못 고침 |
| reset 조향 | 직전 에피소드 끝 상태 이어받기 (컨트롤러 분기 이력도), 20 % 는 범위 안 무작위 | 연속 Nav2 목표와 같은 상황. 설계 v2 의 '무작위 사전 주행' 대신 |
| 지도 나눔 | 학습 real + rand_00..06, 평가 dice + rand_07 | 같은 지도로 평가하면 일반화 주장 불가 |

## 경로

- 지도 경로: `layout_to_occupancy` 격자 → Nav2 식 비용 (내접 0.17 m 253, 팽창 0.25 m · scale 10) → NavFn 식 칸 비용 (50 + 0.8 c) Dijkstra 8 이웃 (대각선 모서리 통과 금지) → 퍼텐셜 경사 하강 → 0.05 m 재표본 → 중심 비용 < 253. 사각 footprint 충돌 검사는 안 함 (NavFn 과 같음). 실제 NavFn 출력과 비교 안 함.
- 합성: 꺾은선 + 원호, 등급 0 (≤45°, ≤2 m) / 1 (≤135°) / 2 (U턴).
- 학습 7800 개 (지도 4800), 평가 1200 개 (지도 600). 길이 중앙 2.4 m · 최대 10 m.
- 커리큘럼: 학습 성공률 (최근 2000 에피소드) 0.9 넘으면 등급 0 → 1 → 2. 초기 위치 ±2 → 5 cm, yaw ±15° → ±180°.

## PPO

actor [128, 128] ELU · critic [256, 256] ELU, 관측 정규화, 초기 std 0.3, entropy 0.001, γ 0.995, λ 0.95, 64 스텝/env, 5 epoch, 4 미니배치, lr 3e-4 adaptive (kl 0.01).

## 남은 것 · 한계

- 간이 플랜트는 접촉 물리가 아님 (최소제곱 순기구학 = 바퀴 어긋남 근사). Isaac 재생 비교 (같은 명령 → 궤적) 로 τ 맞추기 · Isaac 미로 평가 (footprint 충돌 · 최소 여유) 미구현
- `nt_swerve` = 팀 swerve.cpp 10-27 로컬 판. 레포 main C++ 은 옛 판 → 실물에 올라간 판 확인 필요 (control)
- 실물 `/joint_states` 조향각 · 바퀴 속도 제공 · 빈도 · 신선도 미확인 (관측에 필수)
- 실물 조향 속도 (0.96 vs 4.8 rad/s) 미측정 → 측정되면 DR 3 조건을 실측 ±20 % 로
- 잔차 0.05/0.3 vs 0.03/0.15 비교, 커리큘럼 승급을 고정 검증셋 기준으로 바꿀지 (Codex 권고)
- 배포: 가중치 + 정규화 → Nav2 controller 플러그인 (C++) 미구현
- 채택 기준 (Codex 제안): 시뮬 고정 평가 100 회 충돌 0 · 성공 ≥ 99, 실물 대표 경로 20 회 연속, 기준선 대비 중앙 시간 10 % 이상 개선 + p95 오차 · 시간 악화 없음
